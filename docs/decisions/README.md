# Decisões técnicas

Registre aqui decisões que afetem arquitetura, interface pública, dependências
ou manutenção. Cada decisão deve ficar em um arquivo Markdown numerado, por
exemplo `0001-cliente-http.md`, contendo contexto, decisão, consequências e
status.

## Decisões registradas

- [0001 — Escopo do MVP 0.1.0](0001-escopo-mvp.md): limita a versão inicial a
  Materiais e define público, casos de uso, retornos, paginação, erros,
  exclusões e licença MIT.
- [0002 — Interface pública do MVP 0.1.0](0002-interface-publica-0.1.0.md):
  consolida as seis funções exportadas e os contratos de validação, retorno,
  paginação e erros.

O levantamento de endpoints incluídos, adiados e excluídos está na
[matriz de Materiais da versão 0.1.0](../endpoints/matriz-material-0.1.0.md).
