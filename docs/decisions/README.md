# Decisões técnicas

Registre aqui decisões que afetem arquitetura, interface pública, dependências
ou manutenção. Cada decisão deve ficar em um arquivo Markdown numerado, por
exemplo `0001-cliente-http.md`, contendo contexto, decisão, consequências e
status.

## Pendências

- **Licença:** escolher antes da primeira distribuição. A licença MIT é uma
  opção simples e permissiva; Apache License 2.0 e GPL-3 também devem ser
  avaliadas conforme os objetivos de distribuição e reciprocidade do projeto.
- **Interface pública:** definir depois do levantamento dos endpoints de
  Materiais; nenhum contrato público foi assumido nesta configuração inicial.
